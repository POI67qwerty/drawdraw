# 囲って塗る／消す（ブラウザ版）

Clip Studio Paint の「隙間なく囲って塗る／消す」をブラウザで再現するツールです。線画を開き、ブラシでなぞるか投げ縄で囲むと、線で区切られた領域を隙間なく塗ります。Mac と iPad の Safari／Chrome で動くように作っています。

## 使い方

1. 線画を開きます（ボタンで選ぶ、ドラッグ＆ドロップ、または Cmd+V で貼り付け）。
2. 動作（塗る / 消す / 塗り分け）と形（ブラシ / 投げ縄）を選びます。
3. なぞる／囲んで、指を離すと計算されます。
   - **塗る＋ブラシ**：塗りたい領域を**覆うように** なぞります（クリスタの「隙間無く囲って塗る＋消すブラシ」 same）。離すと、覆った範囲にある線囲みの領域を、線の縁まで**隙間なく**塗ります。
   - **塗る＋投げ縄**：塗りたい所を囲みます。囲みの中の領域を線の縁まで隙間なく塗ります。
   - **消す**：なぞりの**中心線**からブラシ半径の範囲で、**線に突き当たるまで**消します（クリスタの「エッジに沿って消去」 same）。かすれた線の縁も縁とみなすので、線を越えて消えることはありません。
   - **塗り分け**：線で区切られたパーツごとに色を分けます。
4. 保存メニューから PNG を書き出します（塗りのみ／線画あり、透過／白背景）。

### 「隙間なく」の仕組み

- 塗りは線のアンチエイリアス（半透明の縁）の下まで色を入れるので、線の縁に白い隙間も色のにじみも出ません。
- 線に小さい切れ目があっても「隙間閉じ」の幅までなら閉じて塗り、外へは漏らしません。
- なぞり／囲みが**線を越えて背景に触れていても**、背景まで塗られないように、囲みが領域の半分に満たない領域は塗りません（消すは除く）。

### キー

| キー | 動作 |
| --- | --- |
| F / E / S | 塗る / 消す / 塗り分け |
| B / L | ブラシ / 投げ縄 |
| H（またはスペースを押している間） | 移動 |
| `[` / `]` | ブラシの大きさ |
| `+` / `-` / `1` / `0` | 拡大・縮小・100%・全体表示 |
| Cmd/Ctrl+Z / Shift+Cmd/Ctrl+Z（または Cmd/Ctrl+Y） | 元に戻す / やり直し（50 段まで） |
| Cmd/Ctrl+S | 保存（PNG） |

### 設定

- **線として認識する濃さ**：この値以上に濃い画素を線とみなします（既定 50）。
- **白背景を透過化**：白い背景を線の判定から外します。
- **隙間閉じ**（0〜30px、既定 8）：この幅以下の隙間を閉じて、外へ漏れないようにします。
- **線の下へはみ出し**（0〜6px、既定 1）：塗りを線の下へ少しはみ出させます。
- **既存の塗りを守る**：すでに塗った所を上書きしません。
- **線に沿う／線を無視**：線を無視すると、線の判定を使わずに塗ります。
- **塗り分け**：領域ごと（parts）か、まとめ％（小さい領域を隣に統合）で分けます。

## 開発

```sh
npm test       # fillcore の単体テスト（node:test）
npm start      # python3 -m http.server 8000 --bind 0.0.0.0
```

ブラウザで http://localhost:8000 を開きます。

## ファイル構成

- `index.html` … 画面（日本語 UI）
- `style.css` … 見た目（明るい／暗いテーマ、狭い画面用の表示）
- `script.js` … 画面の操作、描画、保存、undo／redo、タッチ操作
- `fillcore.js` … 塗りつぶしの核となる処理（ブラウザでも Node でも読み込める）
  - `labelRegions`：壁（線・既存の塗り）から部屋を作り、隙間を閉じる
  - `fillRegion`：一つの領域を塗る
  - `splitRegion`：画像全体を領域ごとに分ける
- `tests/fillcore.test.js` … `fillcore.js` のテスト

## 既知の制限

- 隙間閉じは、隙間の幅がおよそ「隙間閉じの値 × 2」以下のものだけを閉じます。それより広い隙間は、囲みを狭くするか、隙間閉じの値を上げてください（閉じられない隙間は、そこで塗りが止まります）。
- 塗るで領域の半分未満しか覆えなかったときは塗りません。状態バーにメッセージが出ます。
- 消すは線の下（アンチエイリアスの下）の塗りは残します（クリスタの参照レイヤー同様、線を守ります）。
- 「にじみ」の値より細い線（2px 以下など）や、線が T 字に交差する所では、塗ったときに線の反対側の縁にわずかに色が付くことがあります。
- iPad では大きな画像（約1,670万画素を超える分）を縮小して開きます。

## 開発メモ

- `tools/` は Node だけで動く検証用ハーネスです（合成線画を作って塗りを PNG に書き出し、目視確認できます）。本体には影響しません。
  - `npm test`：塗り分けコア（fillcore）の単体テスト（12 ケース）。
  - `npm run e2e`：最小の DOM/Canvas スタブの上で本体 `script.js` をそのまま動かし、ブラシ・投げ縄・消す・undo/redo を通し検証して `tools/out/e2e_*.png` に書き出します。
